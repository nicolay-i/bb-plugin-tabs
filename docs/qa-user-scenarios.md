# Пользовательские сценарии QA Chat Tabs

Desktop: 1440×1000. Mobile/touch: 390×844. Мутации — только в изолированном snapshot с перехватом записей или на временных данных. Не откатывать пользовательские данные. Чек-лист — план, не свидетельство прохождения.

## Вкладки

- Открыть два незакреплённых чата из sidebar → второй заменяет единственную preview, закрепления остаются. [Preview](preview-tab.md).
- Закрепить preview двойным кликом, открыть другой чат, открепить pin → закрепление переживает переход; preview остаётся не больше одной. [Закрепления](pinned-tabs.md), [preview](preview-tab.md).
- Закрыть активную/неактивную вкладку, восстановить последнее закрытие; повторить с New chat → закрывается выбранная, маршрут согласован; восстановлены вкладка и её позиция. [Закрытие](tab-closing.md), [восстановление](closed-tab-restoration.md).
- Перетащить pin в отдельную щель между другими pins, переключить режим и вернуться → порядок сохранён; preview не участвует в drag. [Порядок](manual-tab-order.md).
- Переименовать чат, повторить с Escape и пустым вводом → валидное имя обновлено на всех поверхностях; отмена ничего не записывает. [Переименование](chat-renaming.md).

## Список и New chat

- Открыть список кликом/ArrowDown, найти чат по названию/проекту, выбрать стрелками и Enter → поиск сфокусирован, открыт нужный чат; Escape закрывает меню. [Список](chat-list-menu.md), [поиск](chat-search.md).
- Очистить поиск, раскрыть дерево родителя и вложенное submenu, выбрать ребёнка → вложенность доступна; поиск при этом остаётся плоским. [Подчаты](subthread-navigation.md).
- Посетить незакреплённый чат, открыть историю, скрыть её настройкой → посещение записано; скрытие секции историю не удаляет. [История](chat-history.md).
- Добавить favorite, открыть New chat и его карточку, убрать favorite, выполнить Undo удаления карточки → избранное независимо от pins, переход и Undo относятся к выбранному чату. [Избранное](favorite-chats.md), [New chat](new-chat-screen.md), [Undo](homepage-card-undo.md).
- Открыть «+», выбрать проект → New chat нужного проекта; закрепления не изменены. [Меню проектов](recent-projects-menu.md).

## Режимы

- Переключить Work → Home → Work → восстановлены независимый набор и последний чат; другое окно не переключено. [Переключение](workspace-switching.md), [оконный выбор](window-local-selection.md).
- Создать режим через управление → строка добавлена, текущий режим и маршрут не изменены. [Создание](workspace-creation.md), [управление](workspace-management.md).
- Переименовать режим, отменить вторую правку → сохранено первое имя, черновик создания не очищен. [Переименование](workspace-renaming.md).
- Удалить неактивный/активный временные режимы с подтверждением, попытаться удалить последний → удалён только выбранный набор, активный сменился безопасно; последний защищён. [Удаление](workspace-deletion.md).

## Подчаты и статусы

- Открыть родителя с working, unread, waiting и завершёнными детьми → ⑂ считает только работающих потомков; unread завершённого не увеличивает число. В дереве unread-точка стоит у соответствующего ребёнка; выбор открывает его. [Дерево](subthread-navigation.md), [working](working-indicator.md), [unread](unread-indicator.md).
- Перевести тестового агента working → waiting → completed; открыть непрочитанный main/sidechat → статусы различимы, unread очищен после чтения, метка родства сохранена. [Waiting](waiting-for-input.md), [sidechat](sidechat-activity.md), [метка родства](subthread-badge.md).

## Меню и настройки

- Открыть контекстное меню активной/неактивной вкладки, выполнить pin/favorite/copy-link/цвет/закрытие → действие относится к выбранной вкладке; Escape не изменяет данные. Архивирование/удаление — только на временном чате. [Меню](tab-context-menu.md), [ссылка](chat-link-copy.md), [lifecycle](archive-delete-lifecycle.md).
- В General изменить видимость полосы/списка/истории, tree и workspaces → меняется только выбранное поле, pins/favorites сохранены; вернуть тестовые значения. [Настройки](plugin-settings.md), [отключённые режимы](workspaces-disabled.md).
- В Appearance изменить палитру, alias/цвет проекта и цвет вкладки; перейти General → Appearance → черновик сохранён, Save меняет только выбранное поле; удаление alias не удаляет проект/чаты. [Оформление](plugin-settings.md).

## Клавиатура и touch

- С двумя вкладками нажать Ctrl+Tab / Ctrl+Shift+Tab → цикл по ручному порядку, активная вкладка видима; Shift+Tab остаётся focus traversal. [Клавиатура](keyboard-shortcuts.md), [фокус](hover-and-focus.md).
- Дважды чисто нажать и отпустить Shift за 350 мс, в том числе из composer → список открыт, поиск сфокусирован. Добавить букву, Shift+букву, pointerdown, blur, repeat или IME между нажатиями → список не открыт. [Двойной Shift](keyboard-shortcuts.md).
- Закрыть тестовую вкладку и нажать ⌘⇧T / Ctrl+Shift+T → восстановлено последнее явное закрытие; dialog/rename блокируют фоновое действие. [Восстановление](closed-tab-restoration.md), [ограничения клавиатуры](keyboard-shortcuts.md).
- В Mod+Shift+P проверить 23 регистрации: 1…8/последняя, pin/favorite, следующий режим, F2, parent/tree/list, copy-link, close-others, move-left/right, next/previous/restore → доступность и действия соответствуют контексту. Проверить физические P/S/W с русской раскладкой и Option; parent/tree без default shortcut. [Палитра и shortcuts](keyboard-shortcuts.md).
- На touch 390×844 открыть список/дерево/контекстное меню/управление режимами, прокрутить полосу и выбрать дальнюю вкладку; открыть General/Appearance → controls доступны тапом, меню внутри viewport; активная вкладка раскрывается, ручная прокрутка не сбрасывается статусами. [Адаптивность](responsive-layout.md), [доступность](theme-motion-accessibility.md).
