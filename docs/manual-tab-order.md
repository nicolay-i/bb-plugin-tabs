# Ручной порядок вкладок

Закреплённые вкладки текущего режима образуют одну горизонтальную последовательность независимо от проекта. Порядок записан в state Chat Tabs и виден другим окнам того же набора; активность, sidebar-сортировка и история его не пересчитывают.

![Единая полоса с вкладками разных проектов](screenshots/current/chat-strip-desktop.png)

Desktop drag начинается только на pin. Цель — отдельная подсвеченная щель между закреплёнными, включая межпроектную границу, а не левая/правая половина каждой карточки. Источник становится полупрозрачным; у краёв область автопрокручивается. После drop сохраняется адресованное перемещение.

Preview всегда последняя, не является drag source или target. Она не «прикрепляется случайно» при сортировке. Перемещение кнопки списка слева направо в настройках тоже не меняет порядок чатов.

Этот же порядок используется закреплённой секцией [меню](chat-list-menu.md), домашними [карточками](new-chat-screen.md) и циклом `Ctrl+Tab`. На touch предлагается native горизонтальный swipe, а не обещание HTML drag-and-drop как поддерживаемого жеста перестановки.
