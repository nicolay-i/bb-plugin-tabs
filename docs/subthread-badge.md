# Значок сабтреда

Дочерний чат визуально отмечается компактным значком ветвления, без постоянного текста «Сабтред». Root-чаты такой метки не имеют. Это metadata родства, а не индикатор работающего агента или счётчик детей.

![«Исследование ошибки» отмечено как сабтред](screenshots/current/new-chat-lists.png)

Значок используется в полосе, закреплениях, истории, поиске и домашних карточках. Tooltip и accessible label локализованы; название самого чата остаётся пользовательским. Рабочий, waiting и unread-статусы показываются рядом независимо.

`parentThreadId` сохранён как необязательное поле metadata вкладок, избранного и истории. Старые snapshots без поля остаются валидными; startup-сверка восстанавливает известное родство через уже существующий lookup. Исчезновение чата из текущего sidebar-снимка не должно стереть сохранённую метку.

Метка не раскрывает дерево самостоятельно: [счётчик дочерних чатов](subthread-navigation.md) — отдельный контрол для навигации. Она также не доказывает sidechat: скрытые sidechat могут быть связаны с источником без `parentThreadId`.

Связанные заметки: [sidechat](sidechat-activity.md), [метаданные и миграция](storage-and-migration.md), [локализация](interface-language.md), [карточки](new-chat-screen.md).
