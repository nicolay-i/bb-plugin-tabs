# Закрепление и открепление вкладки

Pin удерживает вкладку в текущем режиме при открытии других незакреплённых чатов. Это pin Chat Tabs, а не закрепление строки в sidebar BB. Состояние и ручной порядок общего режима синхронизируются между окнами.

![Закреплённая вкладка предлагает «Открепить»](screenshots/current/tab-context-menu.png)

Preview закрепляется двойным щелчком или пунктом «Закрепить» в контекстном меню. Закреплённые стоят перед preview; проект не создаёт отдельную группу. На [Новом чате](new-chat-screen.md) только pins образуют секцию «Вкладки».

Открепление не закрывает чат: запись становится единственной preview и может заменить прежнюю временную вкладку. Избранное остаётся независимым. В полосе нет постоянной pin-кнопки; действия доступны через контекстное меню и карточки.

Открепление с домашней карточки сохраняется сразу, но карточка остаётся до окончания посещения с кнопкой повторного закрепления. Это [visit-local отмена](homepage-card-undo.md), не отсроченная серверная запись.

В режиме до 100 вкладок всего. Операции не обещают бесконечный pin-каталог; [восстановление закрытий](closed-tab-restoration.md) не вытесняет другие записи при заполненном наборе. Связанные заметки: [preview](preview-tab.md), [перетаскивание](manual-tab-order.md), [избранное](favorite-chats.md), [лимиты](limits-and-boundaries.md).
