# Новый чат: вкладки и избранное

На штатном экране «Новый чат» BB плагин размещает под composer две секции текущего режима: «Вкладки» и «Избранные чаты». Первая содержит только закреплённые записи в ручном порядке; preview туда не входит. Вторая содержит независимое избранное в порядке добавления, включая чаты без открытой вкладки.

![Закреплённые и избранные карточки на Новом чате](screenshots/current/new-chat-lists.png)

Карточка показывает имя чата и проект. Спокойная карточка не получает фиктивный статус «Нет активности»; работа, ожидание и непрочитанность отражаются только при наличии сигнала. Сабтред отмечен значком ветвления. Клик по избранному явно открывает или восстанавливает preview, затем выполняет штатную навигацию BB.

Кнопка справа сразу сохраняет открепление или удаление из избранного, но оставляет карточку до окончания текущего посещения. Повторное нажатие [отменяет действие на карточке](homepage-card-undo.md), не открывая чат. Это не стек закрытых вкладок.

`showPinnedTabsList=false` скрывает только «Вкладки», не избранное. Переключатель режима переносится в заголовок избранного, чтобы доступ к управлению не исчезал. Открытие этого экрана само по себе не создаёт чат и не записывается как посещение чата.
