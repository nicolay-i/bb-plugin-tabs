# Закрытие вкладки без закрытия чата

X, средний щелчок и поддерживаемый close shortcut удаляют вкладку Chat Tabs из текущего режима. Сам чат остаётся в BB: действие не архивирует его, не удаляет сообщения, не останавливает агента и не снимает избранное.

![У каждой вкладки собственная кнопка X](screenshots/current/chat-strip-desktop.png)

Если закрыта неактивная вкладка, маршрут не меняется. Для активной выбирается другая вкладка того же проекта, если она есть; иначе первая оставшаяся другого проекта. Последняя закрытая возвращает в штатный Новый чат с фокусом prompt, без создания пустого чата на сервере.

Средний щелчок предотвращает browser autoscroll; другие auxiliary-кнопки не закрывают запись. Только успешно удалённая явная вкладка попадает в оконный [undo-stack](closed-tab-restoration.md). Автоматическая замена preview, archive, удаление membership и действия домашней карточки туда не входят.

Закрытый ID защищён от автоматической синхронизации маршрута, reload и позднего старого окна. Защита хранится в наборе отдельно от undo и имеет лимит 200 последних ID. Явный переход или восстановление может снова открыть чат.

В web `Ctrl+W` обычно принадлежит браузеру. В BB Desktop контролируемое закрытие учитывает фокус BrowserView, модальные окна и capabilities; подробности в [клавиатуре](keyboard-shortcuts.md). См. [архивацию](archive-delete-lifecycle.md) и [избранное](favorite-chats.md).
