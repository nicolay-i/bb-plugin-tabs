# Лимиты и границы ответственности

Chat Tabs 0.1.13 требует BB 0.43+ и Plugin SDK 0.4.97+ по manifest. Для установки/сборки используется публичный plugin API; часть UI-slot остаётся experimental. Изменения native layout BB требуют повторной проверки overlay и локализованной формы, даже если типы проходят.

## Ограниченные данные

- От 1 до 20 режимов; имя — 1–80 Unicode code points после trim, без регистронезависимых дублей и конфликтов с default labels.
- До 100 вкладок и отдельно до 100 favorites на режим; preview не больше одной.
- До 200 защитных закрытых ID на режим. Это не бесконечный blacklist и не restore stack.
- До 100 explicit-close undo-записей на окно, разделённых по режимам.
- До 100 уникальных записей общей истории; меню раскрывает по восемь.
- Поиск возвращает до 30 совпадений, запрос до 300 символов. Предел истории не ограничивает область поиска.
- Проекты раскрываются порциями по 15; chat rename допускает 1–300 символов после trim.
- Startup-сверка bounded до 4100 уникальных сохранённых ID режимов и истории.

## Чего плагин не делает

Workspace Chat Tabs не является git worktree, окружением или проектом BB. Плагин не заменяет sidebar, не хранит тексты сообщений для поиска/перевода, не запускает sidechat, не останавливает агент при закрытии вкладки, не меняет общий native right-panel tab state и не выдаёт публичный доступ вместе с copied URL. Новый чат остаётся composer BB, а не отдельным приложением плагина.

Скриншоты с viewport/touch-emulation не подтверждают физические устройства, native Safari или доставку OS-shortcuts. Установленный range и immutable tag определяют обновление; документация не обновляет установленный плагин автоматически.
