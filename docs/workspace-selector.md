# Переключатель режима

Режим Chat Tabs — отдельный набор вкладок и избранного. Переключатель встроен в штатную верхнюю панель существующего чата через публичный header action; дублирующей кнопки в полосе нет. На «Новом чате» он находится у списков карточек.

![Каталог режимов с отметкой выбранного](screenshots/current/workspace-menu.png)

Desktop показывает полное имя со стрелкой, пока хватает места: чрезмерно длинное имя обрезается в пределах header-slot, полное остаётся в tooltip и accessible description. Compact/mobile показывает первый полный grapheme, а не UTF-16 code unit: emoji с модификатором или комбинируемый символ не разрезается. Размер compact-кнопки — 44×44 px.

Меню содержит полные имена, initials, radio-check выбранного режима и пункт управления. Клик, mouse-hover и клавиатура работают по правилам [фокуса](hover-and-focus.md). Выбор запускает [восстановление активного чата](workspace-switching.md), а открытие управления ничего не переключает.

Header работает даже при выключенной полосе: загружает только каталог и обновляет его после reconnect, без загрузки скрытых вкладок или навигации. При `enableWorkspaces=false` этот контрол скрыт, но данные сохраняются.

Связанные заметки: [управление](workspace-management.md), [выбор окна](window-local-selection.md), [язык имён](interface-language.md), [выключение режимов](workspaces-disabled.md).
