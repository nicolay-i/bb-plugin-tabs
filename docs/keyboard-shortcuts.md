# Клавиатурная навигация и native исключения

Chat Tabs использует клавиатуру только в поддерживаемом контексте и не должен управлять вкладкой за модальным редактором или встроенным браузером. Bare `Shift+Tab` остаётся обратным focus traversal.

## Команды

- `Ctrl+Tab` / `Ctrl+Shift+Tab`: следующий/предыдущий чат циклически по ручному порядку текущего режима. Требуются минимум две вкладки и текущая plugin-вкладка; выбранная прокручивается в видимую область.
- Два чистых нажатия и отпускания Shift в пределах 350 мс: открыть меню списка и фокусировать поиск, включая из composer. Любая другая клавиша во время нажатия или между ними отменяет пару — в том числе Shift+буква на любой раскладке. Pointerdown, blur окна, IME composition и автоповтор также сбрасывают жест; keyup без чистого keydown не засчитывается. Нужна доступная полоса/навигация.
- `Ctrl+Shift+T` / `⌘⇧T`: [восстановить явное закрытие](closed-tab-restoration.md), в том числе на Новом чате.
- `Ctrl+W` / `⌘W` в BB Desktop: [закрыть текущую plugin-вкладку](tab-closing.md) через публичный native close-request bridge. В web сочетание принадлежит браузеру.
- ArrowDown у menu-trigger открывает меню с keyboard ownership; стрелки и Enter в поиске выбирают чат. Escape закрывает menu/dialog или отменяет inline rename.

## Команды палитры BB

Подписи команд используют язык Auto (страница BB/браузер) на момент загрузки плагина, не отдельную настройку языка Chat Tabs; смена подписей требует reload.

Команды зарегистрированы через `app.commands.register`, доступны в палитре `Mod+Shift+P` и переназначаются штатными настройками клавиатуры BB. `Mod` — ⌘ на macOS, Ctrl на остальных платформах. Скрываются действия без подходящей вкладки, родителя, детей или истории закрытия; сдвиг работает только для закреплённых вкладок и не выходит за границы их порядка.

- `Mod+Alt+1…8` — перейти на соответствующую вкладку; `Mod+Alt+9` — на последнюю.
- `Mod+Alt+P` — закрепить/открепить текущую; `Mod+Alt+S` — добавить/убрать из избранного.
- `Mod+Alt+W` — следующий режим циклически, с обычным восстановлением последнего чата.
- `F2` — переименовать текущий чат, но не во время ввода в поле. Запуск переименования из палитры сохраняется.
- Только палитра, без нового default shortcut: к родительскому чату, дерево подчатов текущей вкладки, список вкладок, копирование ссылки, закрытие остальных, сдвиг влево/вправо, следующая/предыдущая вкладка, восстановление закрытой.

В BB 0.47.1 сочетания с Alt и не-ASCII `event.key` сопоставляются через `event.code`: `з/ы/ц` и Option-символы `π/ß/∑` работают как физические P/S/W. Плагин не добавляет обходной keydown-перехват; конфликты default shortcut разрешает хост, и конфликтующая команда остаётся без привязки. Старые Ctrl+Tab, двойной Shift, Mod+Shift+T и native Mod+W не дублируются SDK-привязками.

SDK задаёт один default на все платформы. `Ctrl+Alt+стрелки` заняты системой (рабочие столы GNOME, поворот экрана Intel на Windows), поэтому у родителя и дерева подчатов default нет. На Windows `Ctrl+Alt` — это AltGr, а хост BB 0.47.1 не отличает AltGr: в русской раскладке `AltGr+8` (`₽`) перейдёт на вкладку 8, в немецкой/польской раскладке пересечений больше — их снимают переназначением в Settings → Keyboard. В Safari `⌘⌥W` перехватывает браузер.

## Когда плагин не владеет событием

Модальный dialog/alertdialog, rename, drag, IME/repeat и неподходящий стек/набор ограничивают глобальные tab-команды. Диалог не позволяет фоновому закрытию native окна случайно уничтожить plugin-tab. Настоящий фокус BrowserView имеет приоритет над stale DOM-фокусом: native handler закрывает браузерную вкладку, а не чат Chat Tabs.

Зарезервированные browser/OS-сочетания работают только если клиент передал событие BB. Эмуляция viewport и DOM keydown не подтверждают доставку системного shortcut на реальном Desktop.
