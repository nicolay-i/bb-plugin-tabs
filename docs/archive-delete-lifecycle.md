# Архивирование и удаление чатов

Архивация — изменение самого чата BB, а не закрытие записи Chat Tabs. Пункт «Архивировать» вызывает штатное рекурсивное действие BB: чат и дети архивируются, соответствующие native panes закрываются. Плагин не предлагает собственную silent delete-кнопку; удаление извне BB всё равно обрабатывается по lifecycle.

![Архивные и удалённые записи остаются недоступными в истории](screenshots/current/chat-list-history.png)

Archive/delete сразу убирают memberships, pins, preview и favorites во всех режимах, включая неактивные. История сохраняет disabled tombstone с зачёркнутым названием и статусом. Unarchive делает переход из истории доступным, но не возвращает старые вкладки, избранное или порядок.

Startup/reload сверяет сохранённые ID через публичные metadata lookup, чтобы учесть события, пропущенные при выключенном плагине. Transient/permission failure не трактуется как удаление. Уже известное более новое lifecycle-событие сильнее запоздавшего успешного lookup или restore; недоступный чат не должен воскресать из старого ответа.

Архивация не попадает в [undo закрытых вкладок](closed-tab-restoration.md), а домашняя retained-карточка не отменяет archive. Для поиска архивных metadata есть отдельная настройка, но открытие такого результата из поиска запрещено.
