# Chat Tabs: экраны и поведение

Документация соответствует **Chat Tabs 0.1.13**. Плагин добавляет навигацию по чатам в BB, но не заменяет sidebar, composer или управление агентами. «Режим» и workspace здесь означают один набор вкладок и избранного, а не git worktree или окружение BB.

Каждая заметка описывает самостоятельную поверхность или операцию: что меняется, что сохраняется и какие исключения действуют. Ссылки позволяют читать её отдельно от индекса. На скриншотах реальные компоненты плагина в работающем BB с демонстрационными данными; происхождение и границы проверки описаны в [скриншотах](screenshots/README.md).
