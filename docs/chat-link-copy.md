# Копирование ссылки на чат

«Скопировать ссылку» в контекстном меню копирует абсолютный URL чата на текущем origin BB. Это обычная ссылка на маршрут чата, а не share-токен, экспорт переписки или публичный доступ к серверу.

![Копирование доступно без открытия или переименования чата](screenshots/current/tab-context-menu.png)

Действие не меняет выбранную вкладку, pin, избранное, membership или read-state. Получатель должен иметь доступ к тому же BB; плагин не открывает сетевой порт и не выдаёт права доступа вместе со ссылкой.

В поддерживаемом окружении используется Clipboard API. Если API отсутствует или запрещён, существует textarea fallback; ошибка копирования не должна выдавать успех и менять состояние чата. Origin берётся из текущего BB-клиента, поэтому локальная ссылка останется локальной, пока у пользователя нет собственного remotely reachable origin.

Это действие относится к чату, а не к window-local workspace: открывший ссылку клиент использует свой выбор режима и обычные правила preview.
